# Mini CRM PHP & MySQL

Sistema de gestion de relaciones con clientes (CRM) ligero desarrollado en PHP 7.4 y MySQL utilizando arquitectura MVC tradicional sin frameworks externos.

## Caracteristicas
- Arquitectura MVC pura (Model-View-Controller)
- Conexion persistente mediante PDO con sentencias preparadas
- Autenticacion mediante sesiones nativas de PHP y hashing con bcrypt
- Gestion de prospectos y clientes con seguimiento de estados
- Interfaz clasica con Bootstrap 4 y jQuery
